# 자비스 식대 자동화

자비스 영수증 목록을 읽고 메모에서 인원을 계산한 뒤, 영수금액과 사용목적 `식비`를 입력하고 저장하는 Python 프로그램입니다. 월별 검사, HTML·CSV 미리보기, 변경 적용, 저장 결과 검증을 제공합니다.

## 시작하기 — Mac

Python 3.9 이상과 인터넷 연결이 필요합니다. 배포 폴더 전체를 함께 보관하세요.

1. `setup.command`를 더블클릭합니다. Python 가상환경, Playwright, 전용 Chromium 브라우저를 설치합니다. 최초 한 번만 하면 됩니다.
2. `run.command`를 더블클릭합니다.
3. **1 로그인**을 선택하고, 열린 전용 브라우저에서 자비스에 직접 로그인합니다. 회사가 `주식회사 모인`인지 확인하고 영수증 목록이 보이면 터미널에서 Enter를 누릅니다.
4. **2 검사·미리보기**를 선택하고 `2026-09`처럼 조회 월을 입력합니다. 검사만으로는 자비스에 저장하지 않습니다.
5. 검사가 완료되면 검사 창이 닫히고 일반 Chrome(없으면 Safari)에 미리보기가 열립니다. **수정 예정**과 **확인 필요** 항목을 확인합니다. 화면이 안 보이면 **5 최근 미리보기 다시 열기**를 선택하세요.
6. **3 미리보기대로 적용**을 선택합니다. 표시된 회사·월·건수를 확인하고 `적용`을 입력하면 저장합니다.
7. **4 빠진 항목 확인**을 선택합니다. 전체 월을 다시 읽어 미반영 항목과 새로 등록된 대상 영수증을 확인합니다.

현재 열어 둔 일반 Chrome 세션과 자동화 전용 브라우저는 별개입니다. **처음 한 번은 전용 브라우저에 로그인해야 하며**, 세션이 만료되면 다시 로그인합니다. 비밀번호를 코드나 설정 파일에 넣지 않습니다.

### 미리보기가 안 열릴 때

터미널에 `목록 확인`과 페이지별 건수가 나오면 아직 검사 중입니다. 모든 페이지를 두 번 확인한 뒤 `검사 완료`와 미리보기 파일 경로가 표시됩니다.

- **검사 완료·파일 경로가 표시됨**: 메뉴 **5 최근 미리보기 다시 열기**를 선택하세요. 재로그인이나 재검사 없이 저장된 결과를 엽니다. 그래도 안 열리면 표시된 `runs/검사폴더/preview.html`을 Chrome 또는 Safari로 직접 여세요.
- **중단·오류가 표시됨**: 검사가 끝나지 않아 새 미리보기가 만들어지지 않았을 수 있습니다. 오류 문구를 확인하고, 로그인 만료라면 메뉴 1번으로 다시 로그인한 후 검사하세요.
- **1페이지 다음에 ‘같은 영수증이 반복됩니다’로 중단됨**: 1.0.2 이하 버전의 날짜순 조회에서 영수증이 페이지 경계에 겹치는 문제를 1.0.3에서 수정했습니다. 최신 파일로 업데이트하고 실행 중인 프로그램을 종료한 뒤 `run.command`를 다시 열어 메뉴 2번으로 검사하세요. Git으로 받은 폴더라면 그 폴더에서 `git pull --ff-only`로 업데이트합니다.
- **다른 폴더에서 실행 중**: 검사 결과는 실행한 프로그램 폴더의 `runs/`에 저장됩니다. GitHub로 파일을 내려받은 폴더와 실제 실행 중인 폴더가 같은지 확인하세요.

메뉴 5번은 저장된 검사 시점의 결과를 보여줍니다. 현재 자비스의 최신 내역은 메뉴 2번으로 다시 검사하세요.

## 반영한 규칙

| 대상 | 처리 |
|---|---|
| 일반 점심 | `기존 영수금액`과 `인원 × 10,000원` 중 작은 금액 |
| 이름·인원 표시가 없는 점심 | 1명 |
| 이름이 여러 개 | 직원 ID 기준으로 중복 제거하여 계산. 결제자를 별도로 더하지 않음 |
| 한도 이하 결제 | 금액 유지, 사용목적은 식비로 저장 |
| 유병규·강두원의 야간·야근·저녁 식대 | 1명인 경우 최대 12,000원. 여러 명이면 확인 필요 |
| 이혜영의 날짜·이름만 있는 메모 | 본인 이름이 포함되고 모든 이름을 확정할 수 있는 경우 점심으로 처리 |
| 모인런치·출장·휴일 식대 | 별도 식대로 보고 변경하지 않음 |
| 다른 지출·다른 직원의 야간식대 | 변경하지 않음 |
| 이름이 불명확하거나 인원이 모순되는 메모 | 확인 필요로 분류하고 저장하지 않음 |

기본 대상 지급상태는 **지급대기**입니다. 지급완료·지급거절, 0원·음수는 제외합니다. 점심 외 지출을 제외하는 단어와 약칭은 `config.json`에 있습니다.

### 사람 판단 예시

직원 목록은 검사 때 자비스의 사용자 선택 목록에서 읽습니다. 이름을 임의로 추측하거나 외부 AI에 메모를 보내지 않습니다.

| 메모 예시 | 판단 |
|---|---|
| `점심` | 1명 |
| `점심 김기태, 임희정` | 2명 |
| `점심 김기태임희정` | 이름 분해가 유일하면 2명 |
| `점심 김기태 기태 김기태님` | 동일 직원으로 확인되면 1명 |
| `점심 포함 4인` | 4명 |
| `점심 김기태 포함 4인` | 김기태를 포함한 총 4명 |
| `허선아 외2인(전은정,백지훈) 점심` | 총 3명 |
| `점심 김기태 임희정 포함 4인` | 이름 2개와 명시 4명이 불일치 → 확인 필요 |
| `점심 미등록이름` | 확인 필요 |

등록되지 않은 문구가 남으면 곧바로 “이름 없음”으로 취급하지 않습니다. 이름이 없는 점심은 1명으로 처리하되, 식당명·고객명·추가 설명 등 해석하지 못한 텍스트가 있으면 보류합니다. 동명이인도 보류합니다.

### 약칭·명단 수정

`config.json`의 `aliases`에서 약칭과 성명을 지정할 수 있습니다. 기본 약칭은 기태→김기태, 희정→임희정, 민하→서민하, 보람→정보람, 은주→조은주, 선우→고선우입니다. 해당 성명이 자비스 직원 목록에서 유일하게 확인되어야 자동 적용됩니다.

```json
"aliases": {
  "기태": "김기태",
  "희정": "임희정"
}
```

자비스 목록에 없는 사람을 명확히 확인한 경우 `extra_employees`에 추가합니다. 같은 사람이 이미 자비스 목록에 있으면 추가하지 마세요. ID는 고유해야 하고 `extra:`로 시작해야 합니다.

```json
"extra_employees": [
  {"id": "extra:person-001", "name": "홍길동"}
]
```

설정을 수정하면 **새로 검사**해야 합니다. 설정이 바뀐 상태에서는 이전 계획 파일을 적용하지 않습니다. HTML·CSV를 편집해도 적용 대상은 바뀌지 않습니다. 일부만 적용할 때는 아래 `--only`를 사용하세요.

## 터미널에서 실행

이 폴더에서 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium

.venv/bin/python -m jobis_meals login
.venv/bin/python -m jobis_meals scan --month 2026-09 --open
.venv/bin/python -m jobis_meals preview
.venv/bin/python -m jobis_meals apply --plan runs/검사폴더/plan.json
.venv/bin/python -m jobis_meals verify --plan runs/검사폴더/plan.json
```

`검사폴더`는 실제 생성된 폴더명으로 바꿉니다. **`apply` 명령은 별도 질문 없이 해당 계획을 저장합니다.** 나머지 명령은 영수증을 저장하지 않습니다.

일부 영수증만 적용:

```bash
.venv/bin/python -m jobis_meals apply --plan runs/검사폴더/plan.json --only 12345,12346
```

설치된 Google Chrome을 전용 프로필로 사용할 수도 있습니다. `--browser`는 명령 앞에 씁니다. 로그인과 후속 명령에 같은 브라우저 종류를 사용하세요.

```bash
.venv/bin/python -m jobis_meals --browser chrome login
.venv/bin/python -m jobis_meals --browser chrome scan --month 2026-09
```

## 생성되는 파일

`runs/조회월-실행시각/`마다 다음 파일이 생깁니다.

- `preview.html`: 검색·상태 필터가 있는 미리보기.
- `preview.csv`: Excel에서 열 수 있는 UTF-8 BOM CSV.
- `plan.json`: 검사 당시 내역, 인원·금액 판정과 설정 해시.
- `audit.jsonl`: 저장 시작, 변경 전 값, 저장 후 검증 결과, 중단 사유.
- `apply-시각.json`: 적용된 항목과 오류. 오류가 생기면 나머지는 중단합니다.
- `verify-시각.json`: 전체 재검사 결과와 남은 수정 대상.

로그인 세션은 `.local/browser-profile/`에 보관됩니다. 이 폴더와 `runs/`에는 로그인 정보나 영수증 내역이 있으므로 공유용 ZIP에 넣지 마세요.

## 저장과 검증 동작

목록은 영수증 고유번호 내림차순으로 모든 페이지를 연속 두 번 읽고 같은 결과인지 확인합니다. 같은 결제시각의 영수증이 페이지 경계에서 겹치거나 누락되지 않도록 고유한 순서를 사용합니다. 실제 행의 고유번호 순서와 다음 페이지의 조회 조건·연속된 페이지 번호도 확인하며, 중복 항목을 건너뛰지는 않습니다. 적용 직전에 선택한 영수증의 메모·사용자·지급상태·금액 등을 다시 비교하며, 한 건이라도 바뀌었으면 첫 저장 전에 중단합니다.

각 상세 화면에서도 다시 비교한 뒤 **영수금액과 사용목적만** 입력합니다. 저장 후 상세 화면을 새로 열어 반영 여부와 메모·날짜·지급상태 등 다른 입력값이 유지되는지 확인합니다. 부가세를 직접 수정하거나 재계산하지 않습니다. 자비스가 저장 과정에서 부가세를 변경할 수 있으며, 이 경우 변경 전후를 화면과 audit.jsonl에 별도로 표시합니다. 비정상적인 부가세 값이나 다른 필드 변경은 중단합니다.

이미 목표 금액·식비가 반영된 항목은 다시 저장하지 않습니다. 저장 응답이 늦거나 유실되어도 버튼을 재클릭하지 않고 상세 화면을 조회합니다. 실패·불일치 시 중단하며, 완료된 항목을 자동 복구하거나 되돌리지 않습니다.

자비스는 여러 사용자가 동시에 편집할 수 있어 검사와 저장 사이의 동시 변경을 완전히 막을 수는 없습니다. 실행 중 같은 영수증을 다른 창에서 편집하지 않는 방식으로 사용하세요. 화면 구조가 바뀌거나 로그인 세션이 만료되면 중단합니다. 영수증이 전혀 없는 월도 현재는 빈 계획을 만들지 않고 중단합니다.

`verify`의 “수정 필요 없음”은 자동 확정할 수 있는 대상에 대한 결과입니다. **확인 필요로 보류된 내역은 따로 검토해야 합니다.** 새로 등록된 수정 대상이 있으면 기존 계획에 자동 추가하지 않고 새 검사를 실행합니다.

## 검증 범위와 개발 테스트

2026-09-21 자비스 실제 목록·상세 화면을 바탕으로 구현했습니다. 로컬 모의 사이트 테스트에 더해, 실제 자비스 영수증 1건의 금액과 식비 저장을 확인했습니다. 이때 자비스가 부가세를 변경하는 동작을 확인하여, 적용 실패로 처리하던 검증 로직을 변경 전후 기록 방식으로 보완했습니다. 월별 실행 시 미리보기를 확인하고 필요한 경우 소수 항목부터 적용할 수 있습니다.

2026-09-22 날짜순 조회에서 페이지 사이 중복이 발생하는 문제를 실제 목록과 로컬 테스트에서 재현했습니다. 고유번호순 조회로 수정한 뒤 실제 월 전체를 두 차례 읽어 동일한 결과와 미리보기 생성을 확인했습니다. 중복·잘못된 정렬·페이지 건너뛰기를 탐지하는 테스트도 포함합니다.

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

설치된 Chrome으로 테스트할 때:

```bash
JOBIS_TEST_BROWSER=chrome .venv/bin/python -m pytest -q
```

테스트는 로컬 주소 외 요청을 차단합니다. 이름·인원 계산, 예외 항목, 여러 페이지 조회, 저장 실패, 응답 유실, 중복 실행, 변경된 내역의 적용 차단, 누락 검사를 포함합니다.

구현 참고: [Playwright 로그인 상태](https://playwright.dev/python/docs/auth), [브라우저 프로필](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context), [화면 요소 선택](https://playwright.dev/python/docs/locators), [저장 알림 처리](https://playwright.dev/python/docs/dialogs).
